Evidence Provenance Gate (P0 Integrity Layer)

Invariant Rules Enforced

Every piece of evidence is categorized into one of 8 mutually exclusive provenance types to prevent unsubstantiated claims:

REAL_PHOTOGRAPH PUBLIC_DATASET_ANNOTATION HUMAN_ANNOTATION MODEL_PREDICTION GEOMETRIC_FALLBACK SYNTHETIC_FIXTURE USER_SUPPLIED_METADATA VERIFIED_TEMPORAL_OBSERVATION
  • Rule 1: A geometric bounding-box fallback is strictly prohibited from claiming independent segmentation.
  • Rule 2: A human-supplied bounding box never automatically proves physical object identity.
  • Rule 3: A single static photograph cannot prove physical rest or release without verified temporal observations.
  • Rule 4: User-supplied follow-up metadata without submitted media is classified as METADATA_ONLY and cannot claim independent verification.

The Four Internal Engines

LabelCourt Visual Annotation Evidence Auditor comparing human masks against AI evidence with IoU and boundary metrics. Emits ACCEPT, REVIEW, or UNCERTAIN.
ActionProof Physical Action Verification Engine analyzing before-and-after spatial state transitions. Emits SUCCESS, FAILED, or UNCERTAIN.
EvidenceCore Shared Measurement & Uncertainty Engine computing 2D Laplacian blur variance, boundary proximity, and severe area drops. Accelerated by Rust SIMD kernels.
ReCapture Deterministic Missing-Evidence Recovery Planner mapping visual deficits into precise physical instructions.
